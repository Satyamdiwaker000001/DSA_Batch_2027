# DSA Batch 2027 — Student Repository Guidelines

Welcome to the DSA Batch 2027 practice repository!

This repository is dedicated to consistent Data Structures and Algorithms (DSA) practice. Every student must maintain their own personal folder and organize solutions by **DSA topic, not programming language**.

## 🧑‍💻 Instructions for Students

1. Open the `students/` directory.
2. Create your personal folder using your full name, replacing spaces with underscores. Example: `students/Satyam_Diwaker/`.
3. Inside your personal folder, create subfolders based on DSA topics, such as `Arrays`, `Strings`, `Searching`, or `Trees`.
4. Save each solution inside its relevant topic folder.
5. **Do not create separate folders for programming languages.** All supported languages belong in the same topic folder.
6. Use descriptive filenames and the correct file extension:
   - `Two_Sum.cpp`
   - `Binary_Search.java`
   - `Reverse_String.py`
   - `Palindrome.js`
7. Maintain a `README.md` in your personal folder to document your practice progress if needed.
8. Commit and push your own solutions regularly.

## 📌 Repository Rules

- One personal folder per student.
- All personal folders must be inside `students/`.
- Organize code by DSA topic, never by programming language.
- Keep solution files inside their relevant topic folders.
- Do not modify or delete another student's work.
- Do not upload personal solutions directly to the repository root.
- Never commit passwords, API keys, access tokens, or other secrets.

## 🚀 Getting Started

If the `students/` directory does not exist, create it first using a `.gitkeep` placeholder file.

Then create your personal folder, add topic folders as needed, and start uploading your solutions.

**Remember: One student → One personal folder → Topic-based folders → Code files in any programming language.**

Let's keep DSA Batch 2027 organized and consistent!
